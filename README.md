# 📄 DocQnA AI

DocQnA is an AI-powered PDF Question Answering system.

Users can:
- Upload PDF documents
- Ask questions about the document
- Retrieve semantically relevant answers using embeddings and vector search

## 🚀 Features

- PDF Upload
- Semantic Search
- FAISS Vector Database
- Sentence Embeddings
- Flask Backend
- Modern Responsive UI
## 🛠 Tech Stack

- Python
- Flask
- Sentence Transformers
- FAISS
- NLTK
- pdfplumber
- HTML/CSS

## 📚 AI Concepts Used

- Retrieval-Augmented Generation (RAG)
- Semantic Search
- Embeddings
- Vector Similarity Search
